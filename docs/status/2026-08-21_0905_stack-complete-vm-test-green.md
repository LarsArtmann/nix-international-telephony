## Issues found and fixed during verification

1. `digitString` type rejected `""` sentinel defaults → switched to `nullOr`.
2. Escaped-dollar literal split across two Nix strings re-enabled
   interpolation → single-literal form restored.
3. `lib.escapeJSON` does not exist → local `escapeJs`.
4. `genAttrs` partial application passed system strings where pkgs expected
   → `eachSystem` helper.
5. `apps.vm` missing `type`.
6. Python type-checker rejected mixed testScript indentation → rewritten.
7. `sofia status profile` output has no "RUNNING" line → assertions adjusted.
8. nginx runs unprivileged: self-signed key had to be `root:nginx 0640`
   (and `getent` is absent in unit PATH → coreutils-absolute script).
9. **SIP.js API check caught a crash**: `SIP.Web.defaultSessionDescriptionHandler`
   does not exist in 0.21.2; correct is `defaultSessionDescriptionHandlerFactory()`
   (verified by evaluating the shipped bundle in node). app.js fixed +
   register-delegate throw removed.

## Known limitations (documented in README)

- Secrets live in the world-readable Nix store (use a secret manager for
  exposed deployments).
- Emergency calling (911/112) is not wired; no location handling.
- TURN credentials are embedded in the served config.js by design.
- aarch64 outputs are declared but only validated by evaluation
  (`flake check` on x86_64 skips them).
