## 2. Architecture decisions made (and why)

1. **FreeSWITCH 1.11.1 from nixpkgs** (package + upstream NixOS module exist; module supports `configTemplate` + `configDir` file overrides — ideal for generating config from Nix).
2. **No FusionPBX / no FreePBX**: neither is in nixpkgs; both are PHP app frameworks with interactive installers — poor fit for a hermetic Nix module. Rejected for v1.
3. **Web softphone = hand-written static page + SIP.js 0.21.2**, bundled to a classic IIFE global with esbuild (verified working). No CDN, no bundler at runtime.
4. **nginx terminates TLS and proxies `wss://host/sip` → FreeSWITCH `wss-binding`** — single public port 443, browser only trusts one cert.
5. **coturn** for STUN/TURN NAT traversal (upstream module sufficient).
6. **Browser bundle trick**: npm tarballs of sip.js and jssip ship **no `dist/`**; esbuild-bundling `lib/index.js` with `--global-name=SIP` is the hermetic path (smoke-tested: `SIP.version`, `SIP.UserAgent`, `SIP.Web` all present, 267 KB minified).
7. **FreeSWITCH prompts/MOH**: upstream sound tarballs (callie 8k + music 8k, both 1.0.52) fetched via `fetchurl`, wired through `sound_prefix` / `local_stream` config — otherwise voicemail is unusable.
