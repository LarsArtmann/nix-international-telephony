07Guards

An auto-commit daemon commits every few minutes

Every save of a tracked file must leave the tree parseable. Round 1 pushed three unparseable intermediate commits that way. Parse and compile each touched file before starting the next edit.

Tests that pinned a bug

Read the existing test module before changing behavior. An eval-level or unit pin can bless the defect (the SSO-only lane, 2026-11-21). Change the pin in the same batch and say so in the CHANGELOG.

No speculative rewrites

Structural splits of six large files are out of scope for this round. Each fix is the smallest change that removes the defect and carries a test.
